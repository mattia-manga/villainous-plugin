# Villainous Plugin

Plugin per Claude con 26 skill, una per ogni Cattivo di **Disney Villainous**: obiettivo, mazzi Cattivo/Fato con costi e Forza, luoghi, strategie per giocarlo e per contrastarlo.

Contenuti basati sulle guide di Villainous Italia. Disney Villainous e i personaggi sono marchi dei rispettivi proprietari; progetto non ufficiale, solo uso personale.

## Struttura

Il plugin contiene `.claude-plugin/plugin.json` e la cartella `skills/` con una sottocartella per personaggio (es. `skills/villainous-ade/SKILL.md`).

## Uso

Chiedi a Claude, ad esempio, "come gioco Ade?" oppure "come contrasto Jafar?".
